# cositadelocos

Afinador cromático para guitarra, bajo de cuatro cuerdas y ukulele soprano. Web Audio captura la señal del micrófono, YIN estima la frecuencia y el navegador guarda las afinaciones personalizadas y favoritas.

## Publicar en GitHub Pages

Coloca estos archivos en la raíz de la rama `main`. En Settings → Pages, selecciona Deploy from a branch, elige `main` y `/(root)`, y guarda. GitHub mostrará la URL del sitio tras desplegarlo. Abre esa URL con HTTPS para habilitar el micrófono. En GitHub Free, GitHub Pages se publica desde un repositorio público.

[Guía de publicación de GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
